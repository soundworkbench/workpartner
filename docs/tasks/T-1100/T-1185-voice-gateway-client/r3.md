## 必改
1. `gateway/tests/voice.test.mjs` 约 87 行（再加约 44 行的 `req.on('error', reject)`）：「oversized … 413」用例在 chunked 分支一次写 4 MiB，网关回 413 后销毁连接，客户端还在写，常常先收到 `write ECONNRESET`，Promise 直接被拒绝。审核本机（Node 22，能监听 127.0.0.1）：单跑该用例 30 次失败 12 次。改测试写法，不改产品逻辑：
   - 测试服务端记录 handler 回的状态码（例如包一层 `res.writeHead` 存进 `reads[i].status`），用它断言 413；
   - 超限请求客户端遇到 ECONNRESET/EPIPE 时，只要服务端已记到 413 就算通过；或改成分小块写、收到响应就停写。
   - 约 113-115 行慢速上传 408 用例有同样竞态，用同一办法加固。
2. GitHub Actions 浏览器组 `voice`（`tools/browser-tests/voice.e2e.mjs`）在 0c69220 上失败 3 项：
   - 约 200-208 行「microphone denial and unsupported browsers show the prescribed messages」：点击 `button[aria-label="语音输入"]` 超时，按钮是 `aria-disabled="true"`、title「当前浏览器不支持语音输入」，Playwright 认为不可用一直等。不支持的浏览器场景要么用 `click({ force: true })`/直接断言提示与禁用状态，要么检查按钮在该场景下是否应真的禁用（与 brief 对照，按 brief 的预期行为写断言）。
