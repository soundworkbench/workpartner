1. 模型出口选择器会误选网关（render.mjs:116，network-policies.yaml.tmpl:62-79，services.yaml.tmpl:22-27）：modelEgressSelector 若是 gatewayLabels 的子集（会选中网关 Pod）则报错；并要求选择器必须包含 `workpartner/role: model-egress`（规格「名称与标签」已固定该角色值），缺则报错。
2. 模型地址优先级（render.mjs:33）：用户容器实际用 model.baseUrl（gateway/runtime/index.mjs:18 → docker.mjs:107 写入环境变量）。改为以 model.baseUrl 为准；若同时配置了 nextBaseUrl 且主机名或端口与 baseUrl 不一致，报错并说明两者必须一致。
3. --output 文件名可能撞名（render.mjs:244）：改用对象名里不会出现的分隔符（如 `kind_namespace_name.yaml`，集群级对象无 namespace 段），并在写文件前检查重名，重名报错。
4. --output 目录残留（render.mjs:241-246）：目标目录存在且非空时报错退出（提示用户换空目录），不自动删除任何文件；帮助文本写明。
5. 网关持久文件路径（render.mjs:59-61、122-125）：校验 sessionKeyFile、cookieFile、identity.appSecretFile 位于 secureDirectory 或 stateDirectory 之下；配置了 runtime.migration 时 ownersFile 也要校验。不满足时报错（与缺失项一并列出）。
6. hostPort 入口（render.mjs:64-67、140-142）：hostIP/hostPort 与 runtime.localAddress 不一致时，向 stderr 输出提示（不报错），说明隧道指向的是 localAddress。
7. 网关容器加 securityContext：allowPrivilegeEscalation: false、seccompProfile RuntimeDefault、capabilities drop ALL；不要改 runAsUser（保持镜像现有用户，hostPath 属主不变）。
8. 网关资源（gateway.yaml.tmpl:36-39）：增加可选配置 runtime.k8s.gatewayResources（cpu、memory，缺省保持现值 500m/512Mi，requests=limits），写进 docs/organization.md 对应字段说明。
9. 报告里写明：clusterIP 模式额外的 `<gateway>-entry` Service；系统命名空间 configmaps 只允许 get 指定名字（K2a 必须单对象 get）；PriorityClass 名 `<systemNamespace>-gateway` 为集群级对象（K8 清理需知）；网关环境变量覆盖在 k8s 下不可用、须写进组织配置；镜像登记 ConfigMap 重新 apply 时须用 --only 排除。
