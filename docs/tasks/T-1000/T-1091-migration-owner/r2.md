3. 常驻保障依赖的 inspect 字段（gateway/aionui.mjs:316-317）：协调者已决定改合同，K2a（并行返工中）的 inspect 增加 `replicas`（StatefulSet spec.replicas，无则 null）和 `annotations`（无则 {}）。保持使用这两个字段，但：Docker 运行时不返回它们时（undefined）行为与 main 一致；`replicas === 0` 才视为已停用，null/undefined 不视为停用。在报告「对其他 K 任务接口的假设」写明。测试里的假 inspect 按此合同构造，并补 undefined 的用例。
