## 必改
`tools/k8s/adopt-user.mjs:76`：`options['host-secure'] ?? runtime.hostSecure ?? runtime.secureDirectory` 对空字符串无效。`gateway/organization/resolve.mjs:128` 未配置 hostSecure 时给 `''`，结果钥匙目录变成 `''`，K2a 会读当前工作目录下的同名钥匙文件。
- 空字符串按未配置处理，依次回退。
- 最终钥匙目录必须是绝对路径，否则在任何写操作（停 Docker、改归属、建对象）之前就拒绝并报错。
- switch 的前置检查里确认本人钥匙文件存在且可读，缺钥匙时在停 Docker 之前就失败。
- 补用例：hostSecure 为 `''` 时回退到 secureDirectory；结果是相对路径时拒绝且没有任何写操作；钥匙缺失时 switch 不停 Docker。
- 同步修正 usage 和 report.md 里对回退顺序的描述。
