# T-1467 第 2 轮返工：桌面 WS 握手不能先走迁移转发

## 原任务

## 必改（审核第 1 轮）
`gateway/gateway.mjs` 约 426 行：在桌面 WS 路由之前就调用了 `migration.forward(req, socket, null, head)`，会把迁移用户甚至本地用户的桌面握手以**空用户**转发；对端再次命中迁移环路并返回 502/503，违反契约「多网关迁移时 migration.forward 透明转发 WS 升级」的验收。

要求：
1. HTTP `upgrade` 处理里先匹配 `/_wp/desktop/ws`，交给 relay 用 `wpd.` 令牌鉴权得到真实用户；
2. 鉴权后若该用户在迁移中/归属其他网关，再以真实用户调用 `migration.forward` 透明转发；本网关用户走本地中继；
3. 非桌面路径的升级保持原有处理顺序与行为不变；
4. 对端网关收到转发的桌面握手不得再次触发转发（防环），行为按现有 migration 约定。

## 测试
